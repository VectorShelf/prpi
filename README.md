# استوديو عروض المنصات

أداة في صفحة واحدة لإعداد العروض الفنية والمالية لمشاريع تصميم وتطوير المنصات والأنظمة، وتصديرها PDF.

## المزايا
- أقسام جاهزة: المقدمة، نطاق العمل، المستخدمون والصلاحيات، وحدات المنصة، نماذج الواجهات (موك أب)، المنهجية، البنية التقنية، النسخة التجريبية مع QR، الجدول الزمني، الدعم الفني، التسعير والدفعات، الباقات، الشروط والاعتماد.
- إخفاء أي قسم أو إعادة ترتيبه، وعرض الفني فقط أو المالي فقط.
- لوحات موك أب: شاشة مكتبية، لابتوب، جوال، تابلت، متصفح، بخلفيات متناسقة مع لون الهوية.
- هويات متعددة: الشعار والألوان وبيانات الجهة والحساب البنكي والختم.
- توزيع تلقائي للمحتوى على صفحات A4.
- تصدير PDF بثلاث جودات.

## التشغيل
افتح `index.html` في المتصفح. تُحفظ العروض والصور في متصفحك على هذا الجهاز؛ استخدم «نسخة احتياطية» لنقلها.
